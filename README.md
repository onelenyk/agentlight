# AgentLight

Маленька лампа на ESP32-C3 Super Mini, яка кольором показує, що зараз робить AI-агент. Стоїть на столі, живиться від USB-C, стани отримує по WiFi від хуків агента — Claude Code, OpenCode, Antigravity, Codex та інших — або як MCP-сервер.

![Корпус у зборі](docs/images/case-preview.png)

| Світло | Що означає |
|---|---|
| оранжевий, «дихає» | агент працює |
| червоний, блимає | агент чекає на тебе: дозвіл або питання |
| червоний, рівний | помилка |
| зелений | готово |
| синій, «дихає» | лампа чекає налаштування WiFi |
| фіолетовий, «дихає» | немає WiFi |

Якщо агентів кілька, лампа показує найважливіший стан: помилка > чекає > працює > готово.

## Що вона вміє

- **Показувати стан агентів** — працює, чекає на тебе, готово, помилка; на сторінці лампи видно кожну сесію: проєкт, запит, поточну дію.
- **Підключатись до агента однією командою** — хуки й встановлювач лежать у самій лампі.
- **П'ять режимів:** стан агентів, просто лампа з кольором та анімацією, таймер фокусу, шість ігор, Bluetooth-пульт для музики.
- **Сенсор:** дотик, подвійний дотик і утримання виконують дії, свої в кожному режимі; довге утримання перемикає режим.
- **Пульт:** лампа — ще й Bluetooth-клавіатура: керує музикою на комп'ютері чи планшеті й шле клавіші F13–F16, на які можна повісити свої команди.
- **Налаштовуватись без кабелю** — через власну точку доступу або по Bluetooth; пам'ятає до п'яти мереж WiFi.
- **Оновлюватись однією кнопкою** — прошивку збирає й підписує GitHub Actions, лампа приймає лише підписану.
- **Дозволяти агентові дію дотиком** — експериментально, для Claude Code й OpenCode.

## Зібрати свою

1. **Купити деталі** — [список компонентів](docs/bom.md): плата, три діоди на круглих платках, сенсорна кнопка, резистор, дріт.
2. **Надрукувати корпус** — п'ять деталей у трьох кольорах, без підтримок: [файли й налаштування](docs/case.md).
3. **Спаяти** — [схема й порядок пайки](docs/wiring.md).
4. **Прошити** — `cd firmware && pio run -t upload`: [прошивка](docs/firmware.md).
5. **Підключити до WiFi** — по Bluetooth зі сторінки `web/setup.html` або через точку доступу лампи: [сайт](docs/site.md).
6. **Під'єднати агента** — одна команда зі сторінки лампи: [підключення агентів](docs/hooks.md).

![Схема підключення](docs/images/wiring.png)

## Швидкий старт на новій машині

```sh
git clone https://github.com/onelenyk/agentlight.git && cd agentlight

python3 web/serve.py                       # сайт: http://localhost:8791/web/

cd firmware && pio run -t upload           # прошивка (потрібен PlatformIO)

python3 -m venv .venv && .venv/bin/pip install -r case/requirements.txt
.venv/bin/python case/build.py             # перебудувати корпус
.venv/bin/python case/verify.py            # перевірити його
```

## Стан проєкту

Усе, що можна перевірити без пальця на сенсорі й без очей, проходить наскрізну перевірку на справжній лампі — результати й спосіб у [docs/e2e-report.md](docs/e2e-report.md). Автотести без лампи йдуть на кожен коміт, перевірка на свіжих версіях програм агентів — щотижня: [docs/testing.md](docs/testing.md).

Агенти:

| Агент | Перевірено на справжній програмі | Не перевірено |
|---|---|---|
| Claude Code | усі п'ять станів; «Дозволити» | чи видно питання у вікні, поки лампа чекає дотику |
| OpenCode | «працює» з назвою інструмента, «готово» | запит дозволу, помилка, відповідь лампи на запит дозволу |
| Antigravity IDE | «працює», «готово» (вручну) | помилка; стану «чекає» немає взагалі |
| Codex CLI | «працює», закриття сесії (без входу в акаунт) | «готово», «чекає» |
| Qwen Code | «працює» (без входу в акаунт) | решта станів |
| Copilot CLI, Cursor, Gemini CLI | — | усе: не запускаються без акаунта або не встановлені |

Перевірено руками власника: корпус надрукований і зібраний, деталі сидять добре; налаштування WiFi через точку доступу й по Bluetooth зі сторінки в Chrome; пульт працює з Mac та iPad.

Лишається перевіряти лише руками: жести на живому сенсорі, вигляд анімацій, ігри пальцем, «Дозволити» з живим дотиком.

Обмеження, про які варто знати:

- **Захист мінімальний.** Будь-хто у твоїй мережі WiFi може міняти стан і налаштування лампи; будь-хто поруч із Bluetooth — додати чи забути мережу. Захищені лише оновлення прошивки (підпис або пароль) і «Дозволити» (спарювання дотиком і підпис відповіді).
- **Автоматичного відкату прошивки немає:** якщо оновлення не вийде в WiFi, рятує кабель.
- **Хуки шукають лампу за іменем `agentlight.local`.** На Mac це працює; на частині Linux-систем треба вписати IP. Windows без WSL не підтримується.
- **Сторінка лампи лише українською.**
