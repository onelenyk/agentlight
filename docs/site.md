# Сайт

Тека `web/` — статичний сайт без серверної частини:

| Сторінка | Що робить |
|---|---|
| `web/index.html` | вхід: посилання на налаштування і на превью корпусу |
| `web/setup.html` | налаштування WiFi лампи по Bluetooth |
| `case/preview/index.html` | 3D-превью корпусу, схема, файли до друку |

## Локально

```sh
python3 web/serve.py           # http://localhost:8791/web/
python3 web/serve.py --lan     # ще й для інших пристроїв у мережі
python3 web/serve.py --port 9000
```

Сервер віддає корінь репозиторію, бо сайт посилається на `case/preview/` і `case/stl/`. Потрібен лише Python 3, без залежностей.

## Налаштування по Bluetooth

1. Відкрий `http://localhost:8791/web/setup.html` у Chrome або Edge.
2. Натисни «Знайти лампу» і вибери `AgentLight-XXXX`.
3. Вибери мережу, введи пароль, натисни «Додати і підключитись».
4. Лампа перезавантажиться; сторінка підключиться до неї знову й покаже адресу сторінки лампи.

Лампа пам'ятає до п'яти мереж і сама підключається до тієї, яку бачить поруч, — можна додати домашню й офісну.

Обмеження:

- **Браузер.** Chrome або Edge на Mac, Windows, Android, Linux, ChromeOS. Safari, Firefox і всі браузери на iPhone Bluetooth зі сторінок не вміють. З iPhone налаштовуй через точку доступу лампи: підключись до `AgentLight-XXXX`, сторінка відкриється сама.
- **Адреса.** Chrome дає Bluetooth лише сторінкам з `localhost` або з HTTPS. З `--lan` інші пристрої відкриють сайт по `http://<ip>:8791`, але Bluetooth там не працюватиме.
- **Відстань.** Лампа має бути поруч, до ≈ 10 м.

## Викласти в інтернет

Потрібен будь-який статичний хостинг із HTTPS; викладати треба весь репозиторій, а не лише `web/`. Файл `index.html` у корені перенаправляє на `web/`.

GitHub Pages: Settings → Pages → Deploy from a branch → `main`, тека `/ (root)`. Сайт буде на `https://<акаунт>.github.io/<репозиторій>/`. Безкоштовно Pages працює лише для публічних репозиторіїв.

Пароль WiFi через хостинг не проходить: він іде з браузера прямо на лампу по Bluetooth.
