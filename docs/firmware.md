# Прошивка

PlatformIO, фреймворк Arduino, плата `esp32-c3-devkitm-1` (підходить для Super Mini). Бібліотеки: Adafruit NeoPixel, ArduinoJson 7, NimBLE-Arduino. Займає близько 80% слота прошивки (1,05 з 1,31 МБ).

```sh
cd firmware
pio run -t upload              # основна прошивка
pio device monitor             # лог: стан кожні 5 с, адреса лампи
pio run -e touchtest -t upload # тестова: без WiFi, діоди світять, поки палець на сенсорі
AGENTLIGHT_OTA_PASSWORD=... pio run -e ota -t upload   # оновлення по WiFi, без кабелю
```

Піни задаються в `firmware/platformio.ini`: дані діодів `LED_PIN=4`, до `LED_COUNT=10` діодів у ланцюжку, сенсор `TOUCH_PIN=1`.

## Як вона працює

1. **Запуск.** Читає з пам'яті збережені мережі й налаштування, вмикає Bluetooth.
2. **WiFi.** Шукає в ефірі збережені мережі й підключається до найсильнішої з них. Якщо за 20 с не вийшло або мереж немає — піднімає точку доступу `AgentLight-XXXX` з порталом налаштування (192.168.4.1) і світить синім. Якщо мережі збережені, а до порталу ніхто не підключився, через 3 хвилини перезапускається і пробує знову.
3. **Робота.** У мережі лампа доступна як `http://agentlight.local/` і за IP-адресою. Приймає стани, тримає список агентів, 40 разів на секунду вирішує, чим світити.

### Агенти і пріоритети

Лампа тримає до 8 записів, по одному на `agent_id`. Показує найважливіший стан серед усіх: помилка > чекає > працює > готово. Стан `idle` запис видаляє.

Кожен запис живе обмежений час від останнього оновлення (типові значення, міняються в дебаг-меню; 0 — не гасне):

| Стан | Час |
|---|---|
| працює | 10 хв |
| готово | 5 хв |
| чекає, помилка | 2 год |

Список живе лише в оперативній пам'яті й зникає після перезавантаження.

### Сенсор

TTP223 на GPIO1. На кожен дотик лампа коротко блимає білим. Дії для короткого дотику й утримання (0,8 с) вибираються в дебаг-меню:

| Дія | Що робить | Типово |
|---|---|---|
| `dismiss` | «побачив»: прибирає готово, чекає і помилку; агенти в роботі лишаються | короткий дотик |
| `brightness` | яскравість по колу: тьмяно → середньо → повна | утримання |
| `mute` | вимикає й вмикає світло, агенти рахуються далі | — |
| `none` | нічого | — |

## Сторінка лампи

`http://agentlight.local/` — одна сторінка:

- **Агенти** — картка на кожну сесію: проєкт, запит користувача, поточна дія, скільки часу в цьому стані.
- **Тест** — кнопки станів і яскравість (5–255).
- **WiFi** — збережені мережі (до п'яти) з кнопкою «Забути», додавання нової.
- **Дебаг** — стан плати (версія, час роботи, причина запуску, дата збірки, пам'ять, сила сигналу), живий індикатор сенсора, дії сенсора, кількість діодів, колір кожного стану, часи згасання, оновлення прошивки, веселка на 10 с, очищення агентів, типові налаштування, перезавантаження.

## REST

| Запит | Що робить |
|---|---|
| `GET /api/status` | стан лампи, агенти, яскравість, WiFi |
| `POST /api/status` | виставити стан агента; JSON або параметри запиту |
| `GET /api/debug` | те саме плюс стан плати, сенсор і всі налаштування |
| `POST /api/config` | змінити налаштування; приймає будь-яку підмножину полів |
| `POST /api/action` | `{"action": "rainbow" \| "clear" \| "unmute" \| "defaults" \| "reboot"}` |
| `GET /api/scan` | мережі WiFi поруч |
| `POST /api/wifi` | `{"ssid", "pass"}` — додати мережу і перезапуститись |
| `POST /api/wifi/reset` | `{"ssid"}` — забути одну мережу; без тіла — всі |
| `POST /api/ota/password` | `{"old", "new"}` — задати або змінити пароль оновлення; порожній `new` вимикає оновлення |
| `POST /api/update` | файл прошивки (multipart) і заголовок `X-OTA-Password` |

Стан агента:

```sh
curl -4 -X POST http://agentlight.local/api/status \
  -H 'Content-Type: application/json' \
  -d '{"state":"busy","agent_id":"my-agent","name":"проєкт","task":"що попросили","message":"що робить зараз"}'
```

`state` — одне з `idle`, `busy`, `waiting`, `done`, `error`. Решта полів необов'язкові; `name` і `task` запам'ятовуються до наступної зміни. На macOS для адрес `.local` потрібен `curl -4`, інакше запит 5 секунд чекає на IPv6.

Поля `POST /api/config`: `brightness`, `leds`, `ttl_busy`, `ttl_done`, `ttl_attention` (хвилини), `colors` (`{"busy": "#ff5a00", ...}`), `tap`, `hold`.

## Оновлення по WiFi

У пам'яті плати два слоти під прошивку по 1,25 МБ. Нова прошивка пишеться в запасний слот і стає активною після перезавантаження; налаштування, мережі й пароль зберігаються.

Оновлення вимкнене, доки не задано пароль оновлення: сторінка лампи → «Дебаг» → «Оновлення прошивки». Перший пароль задається без старого, далі для зміни потрібен поточний.

- **Через сторінку лампи.** Там само вибери `firmware/.pio/build/c3_supermini/firmware.bin` і натисни «Залити прошивку». Триває близько 10 секунд.
- **Через PlatformIO.** `AGENTLIGHT_OTA_PASSWORD=... pio run -e ota -t upload`. Триває близько 45 секунд; macOS може спитати дозвіл на вхідні з'єднання для Python.
- **Запитом.** `curl -4 -H 'X-OTA-Password: ...' -F firmware=@firmware.bin http://agentlight.local/api/update`

Під час оновлення лампа світить блакитним. Файл, який не є прошивкою ESP32, лампа відхиляє.

Обмеження:

- Прошивка має влазити в слот 1,25 МБ; зараз вона займає 80%.
- Автоматичного відкату немає. Якщо нова прошивка не зможе вийти в WiFi чи зависне, оновити її по повітрю вже не вийде — лише кабелем.
- Забутий пароль скидається лише повним стиранням по USB (`pio run -t erase`), разом із мережами й налаштуваннями.
- Пароль іде мережею відкритим текстом (HTTP), тож захищає від випадкових людей у твоїй WiFi, а не від того, хто слухає трафік.

## MCP

`POST /mcp` — Streamable HTTP без сесій і без SSE. Інструменти: `set_status` (ті самі поля, що в REST) і `get_status`.

```sh
claude mcp add --transport http agentlight http://agentlight.local/mcp
```

## Bluetooth

Bluetooth LE ввімкнений завжди й потрібен лише для налаштування WiFi. Клієнт — сторінка `web/setup.html` (Web Bluetooth). Лампа рекламує себе як `AgentLight-XXXX`.

Сервіс `a9e10001-7c1e-4b6f-9d2a-41676e744c69`, значення — JSON до 500 байтів:

| Характеристика | Доступ | Значення |
|---|---|---|
| `a9e10002-…` status | читання | `{"name", "state", "portal", "ssid", "ip", "rssi", "saved": [...]}`, оновлюється щосекунди |
| `a9e10003-…` scan | читання | `{"seq", "list": [...]}` — результат останнього пошуку мереж |
| `a9e10004-…` cmd | запис | `{"cmd":"scan"}`, `{"cmd":"add","ssid","pass"}`, `{"cmd":"forget","ssid"}`, `{"cmd":"forget"}` |

Після `scan` клієнт перечитує характеристику scan, доки не зміниться `seq` (пошук триває кілька секунд). Після `add` і `forget` лампа перезавантажується. Збережених паролів лампа по Bluetooth не віддає. З'єднання без сполучення й шифрування.
